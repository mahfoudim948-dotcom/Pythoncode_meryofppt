📝 Exercices de programmation

Exercice 1 : Addition

Écris une fonction add(a, b) qui retourne la somme de deux nombres.

Exercice 2 : Salut Utilisateur

Écris une fonction greet(name) qui retourne "Bonjour, [name]!".

Exercice 3 : Multiplication

Écris une fonction multiply(a, b) qui retourne le produit de deux nombres.

Exercice 4 : Vérifier pair/impair

Écris une fonction isEven(n) qui retourne true si le nombre est pair, sinon false.

Exercice 5 : Compter les voyelles

Écris une fonction countVowels(str) qui retourne le nombre de voyelles dans une chaîne de caractères.

Exercice 6 : Inverser un mot

Écris une fonction reverseWord(word) qui retourne le mot inversé.

Exercice 7 : Maximum d’un tableau

Écris une fonction maxArray(arr) qui retourne le plus grand nombre d’un tableau.
